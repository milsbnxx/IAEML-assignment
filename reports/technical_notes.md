# Technical notes for the author's reflection

These observations come from running the code and inspecting the simulator. Sabina can choose which ones to discuss in her personal reflection.

| Observation | Change made | How to verify it |
|---|---|---|
| The course observation's vector method raised “Zero-dimensional arrays cannot be concatenated.” The scalar distance, direction vector and ray matrix have different ranks. | Construct a fixed 25-value vector in the subclass. Keep ray displacement vectors for the renderer. | The observation tests check all three maps and a known ray distance to a disc. |
| With one metre per grid cell, the default start at (2, 1) is one metre from a boundary obstacle. A taxi and obstacle of radius 1 m need 2 m between their centres. | Convert the original cell centres and waypoints to metres at 3 m per cell. Use the same physical scale in the video. | Each default start survives a zero-action step. |
| Passing the whole configuration through an outer JIT as ordinary data failed on the grid dtype. The original auto-reset wrapper also warned about storing an array as a static field. | Mark the configuration static in the outer compiled step. Keep the wrapper's initial state as a normal Equinox field. | The scalar/batched equivalence test and the course auto-reset test both pass. |
| Under the original route on map 2, the one-map pilot hit obstacles in 64/64 episodes. Training on two maps with the same route still gave 20 collisions and 44 timeouts on the comparison seeds. | Check every route segment against the fixed discs. If one intersects, rerun the course planner using fixed obstacles, then check the replacement route. | On map 2 a route point lay at grid (5, 1), exactly the wall centre at world (15, 3) m. The final route passes the static clearance test. The trained policy reached the goal on all 64 comparison seeds. |
| A traffic disc at the boundary can wrap to the opposite side in one step. A line drawn between the two positions would pass through the middle of the map. | Check relative motion up to the boundary crossing and separately check the wrapped position. | A fixture places a taxi in the middle of a crossing row and checks that a right-edge wrap leaves it safe. |
| The 128-transition smoke test completed zero episodes. A mean return computed over that empty set would be misleading. | Write blank cells for episode-level statistics when the count is zero. Still record update losses, then save, reload and query the model. | Compare the episode count in the smoke CSV with the action saved in its run metadata. |

The environment tests also check real acceleration and braking limits, coasting loss, steering sign, stationary steering, goal entry, simultaneous collision and goal, a timeout, the world edge and finite JIT/VMAP outputs. The three learning tests cover time-limit bootstrapping, tanh probability calculations and checkpoint round trips.
